# 001 · Фоновый режим SafariKeePassXC

Самостоятельная поставка. Сначала прочитать design.md, затем выполнять tasks.md сверху вниз.

| ID | Действие | Ожидаемый результат |
|---|---|---|
| BG-1 | Запустить приложение | Видны окно и иконка Dock. Работает один BridgeServer. |
| BG-2 | Закрыть окно красной кнопкой или ⌘W, свернуть жёлтой кнопкой или ⌘M | Окно, иконка Dock и иконка приложения в строке меню исчезают. Расширение Safari получает статус и заполняет пароль. |
| BG-3 | Открыть настройки расширения из окна приложения | После успешного открытия настроек приложение переходит в состояние BG-2. |
| BG-4 | В фоне повторно открыть приложение из Finder или Spotlight | Тот же PID, одно активное окно настроек, видна иконка Dock. |
| BG-5 | Нажать ⌘Q в активном приложении | Процесс завершается. Расширение получает host_app_not_running. Новый запуск восстанавливает связь. |

Автозапуск при входе и отдельный демон за пределами задачи. Иконка расширения в панели Safari нужна для popup.
